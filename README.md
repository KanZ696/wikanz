# Program Kasir Kafe Kopi (Go)

Aplikasi berbasis Command Line Interface (CLI) menggunakan bahasa pemrograman Go untuk mengelola transaksi pemesanan menu kafe, kalkulasi diskon member, perhitungan uang kembalian, serta pencetakan struk pembayaran.

## 🚀 Fitur Program
1. **Pilihan Menu Minuman & Makanan**: Americano, Caramel Macchiato, Matcha Green Tea, dan Croissant.
2. **Diskon Khusus Member**: Otomatis memotong 10% dari total belanja.
3. **Validasi Input Lengkap**: Memvalidasi nomor menu, jumlah porsi, serta memastikan nominal uang bayar tidak kurang dari total tagihan.
4. **Pencetakan Struk Otomatis**: Menghasilkan struk kasir dengan format mata uang rupiah.

---

## 💻 Cara Menjalankan Program
```bash
go run main.go
```
